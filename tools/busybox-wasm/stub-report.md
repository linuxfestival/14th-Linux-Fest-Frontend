# busybox.wasm stub report

Generated by `tools/busybox-wasm/analyze.mjs`. Lists every libc function compiled as a
stub (or kernel import with limited support) that an applet can reach. In paths, `*name`
marks a call through a function pointer (a possible target with the right signature).
